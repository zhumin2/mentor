# Mentor App —— 做孩子最好的人生导师

一款面向 8-14 岁孩子的「人生导师」App：孩子遇到成长困惑时，有位懂他、信他、能引导他的 AI 导师随叫随到；家长通过透明的周报与对话记录更懂孩子，全程安全可控。

## 核心定位

- **不卷学科提分**（那是学习机的战场）、**不做虚拟玩伴**（2026-07-15 施行的《人工智能拟人化互动服务管理暂行办法》禁止向未成年人提供虚拟伴侣服务）
- 只做**成长引导**：价值观、情绪、社交、习惯、抗挫、自我认知、梦想探索
- 导师黄金准则：先接住情绪再解决问题、不直接给答案、永远引导孩子回到现实
